Тема навчального проєкту

Протягом семестру розробляється інформаційно-довідковий веб-ресурс, присвячений аналізу апаратного забезпечення сучасних смартфонів, оптиці мобільних камер та архітектурі мобільних операційних систем.

Перелік технологій, що вивчаються

  • HTML — структура та семантична розмітка документа
  • CSS — стилізація, CSS-змінні та адаптивна верстка
  • JavaScript — базова інтерактивність
